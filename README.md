# Titanic Survival Prediction

## Objective
Build a machine learning model to predict whether a passenger survived the Titanic disaster.

## Dataset
Titanic Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
- Logistic Regression

## Steps Performed
1. Loaded the dataset.
2. Checked missing values.
3. Removed unnecessary columns.
4. Filled missing values.
5. Encoded categorical variables.
6. Split the dataset into training and testing sets.
7. Trained the Logistic Regression model.
8. Evaluated the model using Accuracy, Precision, Recall, and F1-score.

## Results
- Model Accuracy: **81.01%**

## Conclusion
The Logistic Regression model successfully predicted Titanic passenger survival with approximately **81% accuracy**.
